# Daniel Selbach

Networks, Cybersecurity & Cloud — 12+ years in the field.

Started in the trenches: ISPs, telecom, corporate infrastructure. Day-to-day with routing, switching, firewalls, and the kind of incidents that teach you more than any certification ever will.

Today I run [Sagarys](https://sagarys.com.br) — Active Defense Architecture for enterprise environments. NOC/SOC 24/7, ransomware protection, immutable backup, private cloud and IT governance built as a unified stack.

I study offensive security and Red Team in controlled environments. Not as a career pivot — because understanding how attacks work is what makes defense architecture actually hold.
